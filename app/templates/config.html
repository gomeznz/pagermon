Kiosk displays

A kiosk is a full-screen, read-only Live view for a wall screen or spare monitor. It opens from its own link without signing in, so treat the link like a password: anyone who has it can watch pages. Suppressed pages are never shown on a kiosk. Disabling a kiosk, giving it a new link or removing it cuts off any screen showing it within ten seconds.
