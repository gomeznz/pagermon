Kiosk displays

A kiosk is a full-screen, read-only Live view for a wall screen or spare monitor. It opens from its own link without signing in, so treat the link like a password: anyone who has it can watch pages. Suppressed pages aren't shown on a kiosk unless a capcode or keyword rule forwards them to it. Disabling a kiosk, giving it a new link or removing it cuts off any screen showing it within ten seconds.

Locations & map

Finds addresses in page text and shows them on the Map. An address with a house, RAPID or property number becomes a pin; a street, suburb or town on its own becomes a shaded area. Lookups use OpenStreetMap's Nominatim service by default (New Zealand data includes LINZ addresses and rural RAPID numbers). Turning this on sends the address part of matching pages to that service; point it at your own Nominatim server instead if you'd rather nothing leaves your network. Results are cached and limited to one lookup a second.{% if loc_stats and loc_stats.n %} In the last 24 hours: {{ loc_stats.n }} page{{ '' if loc_stats.n == 1 else 's' }} located, {{ loc_stats.pts or 0 }} to an exact address.{% endif %}
